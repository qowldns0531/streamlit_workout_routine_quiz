# 운동 성향 진단 퀴즈

## 프로젝트 소개
이 프로젝트는 Streamlit을 활용하여 만든 간단한 운동 성향 진단 퀴즈 웹 애플리케이션입니다.  
사용자는 로그인 후 여러 문항에 답하고, 자신의 운동 성향을 확인하고 추천하는 루틴을 확인할 수 있습니다.

## 주요 기능
- 로그인 기능
- Streamlit 캐싱 기능
- 퀴즈 풀이 및 결과 확인 기능
